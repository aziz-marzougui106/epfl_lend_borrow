LendNBorrow — AI-Powered Student Marketplace

A smart peer-to-peer exchange platform built for EPFL students, where an AI agent replaces the traditional search bar.

Instead of manually browsing endless listings, users simply tell the AI what they need in natural language. The agent searches the marketplace database, ranks the most relevant results, and can proactively reach out to students most likely to have the requested item — turning a passive marketplace into an active, conversational experience.

Built with: Flutter · Dart · AI Agent · REST API
